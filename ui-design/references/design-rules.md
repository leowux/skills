# 二十条 UI 设计规则

沿用原文编号，按“识别问题、调整方式、检查与边界”提炼。数值是设计起点，不是每个产品的硬性规格；对比度需针对实际配色测量。

## 风格与起步（01–02）

### 01. 为设计选择一致的个性

- **识别**：字体显得严肃、按钮却过分俏皮，文案又像公文，组件之间气质冲突。
- **调整**：用字体、色彩、圆角、文案共同表达同一基调。衬线、中性无衬线、圆体分别可作为典雅、克制、亲切的起点；小圆角、大圆角、直角也应与基调协调。
- **检查与边界**：比较标题、按钮、表单与提示的风格是否一致。已有品牌优先；颜色的情绪含义依赖场景与文化，不能机械地认定蓝色必专业、金色必高级。

### 02. 别着急上色

- **识别**：移除彩色背景和按钮后，内容失去主次，分组难以辨认。
- **调整**：先靠间距、字重、字号和中性明暗建立骨架，再让品牌色强化主要操作和关键状态。
- **检查与边界**：灰度下仍能看出焦点与归属。已有品牌界面用此原则检查结构即可，无须清除配色；状态含义也要由文字或符号表达。

## 视觉层级（03–06）

### 03. 字号并非万能

- **识别**：标题巨大，说明小到难读，却仍然缺少清晰层级。
- **调整**：先组合字重与文字颜色。可从常规 400/500、强调 600/700，以及主内容、次要内容、辅助说明三类文字 token 起步。
- **检查与边界**：辅助文字在实际背景上仍然可读。小字号避免过细字重；不要把“弱化”理解为降低对比度到不可读，也不把所有字体都锁死为相同数值。

### 04. 通过弱化竞争元素凸显重点

- **识别**：当前导航或重点内容已经加粗、上色，但旁边内容仍同样抢眼。
- **调整**：降低非重点项的字重、填充强度或装饰，让当前项通过相对差异显现。
- **检查与边界**：第一眼能辨认当前焦点，其他可用操作仍容易找到。区分未选中与禁用，不能让普通导航看起来不可点击。

### 05. 删除多余的数据展示标签

- **识别**：资料卡机械罗列“姓名：”“邮箱：”“电话：”，标签和值平分视觉权重。
- **调整**：格式或上下文足够明确时直接展示值，将人名、标题等识别信息作为主层级；其余必要标签根据检索目的确定权重。
- **检查与边界**：只适用于展示数据。表单仍需清晰标签；规格表、指标看板、多个含义不明的数字或相似字段应保留名称和单位。用户按指标名查找时，标签可以比值更突出。

### 06. 按任务重要性决定按钮强度

- **识别**：保存、取消、删除都用实心高饱和样式，用户无法识别下一步。
- **调整**：主要操作用醒目填充；次要操作用浅底或线框；辅助操作用低强调的文字样式。先决定层级，再叠加成功、危险等语义。
- **检查与边界**：同一任务区域通常有一个清晰主操作。删除若不是当前主要任务，应降低视觉强度，但保留明确危险含义；若流程已有删除确认，在确认框中可将删除设为醒目的主操作。此规则不要求为所有删除动作新增弹窗。

## 空间与布局（07–10）

### 07. 从充裕留白开始，再收紧

- **识别**：文字贴边、控件挤在一起，只达到“勉强放得下”的状态。
- **调整**：先给模块、卡片和内容更充裕的内外间距，再放到整页中逐步缩减；复用有限的间距 token，避免逐个元素随意取值。
- **检查与边界**：内容舒展且关联清楚，没有因留白把主要操作推得过远。高密度工作台先看重复记录的扫描效率：减去冗余容器内距、分隔和重复标题，不必让每个字段都像独立模块。保持文字易读、分组清楚和操作目标可用，不能一律套用营销页的大间距。

### 08. 不必填满整个屏幕

- **识别**：简短表单或文章被拉成全屏，输入框和阅读行过长。
- **调整**：按内容设置最大宽度；例如单列表单可从约 600px 试起。导航可以全宽，内容不必跟随；宽屏可将辅助信息放入侧栏。
- **检查与边界**：小屏保留合理边距，宽屏不过度拉伸。需要横向比较的表格与多列工作区可以使用更多宽度，不要给所有页面同一个窄容器。

### 09. 用亲疏间距表达归属

- **识别**：标签与自己的输入框、与上一组输入框距离相同，小标题夹在上下文之间。
- **调整**：让组间距大于组内距；标签贴近对应输入框，小标题更靠近其引出的正文。
- **检查与边界**：不靠额外线条也能看出归属。比较真实内容的间距，包括多行帮助文本和错误提示，而不是只比较空控件的 margin。

### 10. 响应式不等于等比缩放

- **识别**：桌面的标题与正文比例原样搬到手机，标题过大、拥挤或异常折行。
- **调整**：分别调整标题、正文、间距、列数与宽度。通常越大的元素越需要在小屏收敛尺寸差；普通界面标题可试 20–24px，但不据此限制所有标题。
- **密集列表**：先判断用户主要在跨记录比较，还是逐条阅读。横向比较多个指标时可保留表格并只在表格容器内滚动；逐条阅读时可将记录重排为紧凑字段行，将有明确归属的标签和值放在同一行，合并相关字段。保留不自明的名称和单位，避免每个字段都另起标签行、值行，再包一层大卡片。
- **检查与边界**：正文维持舒适可读，标题换行自然，操作区不溢出。依据内容与实际渲染判断，不能为了固定比例把正文一并缩小。

## 文本与排版（11–12）

### 11. 让行长与行高协同

- **识别**：段落跨满大屏、读完一行容易串行；大标题行距松散。
- **调整**：先限制行长，再选行高。拉丁正文可从每行约 45–75 个字符试起；正文行高约 1.5，长行或小字可向 1.8–2.0 调整，大标题可从 1.1–1.2 试起。
- **检查与边界**：检查真实字体与换行后的阅读感。中文字符密度不同，不能直接套用拉丁字符数；`ch`、`em` 与实际字符数量也不能简单等同。行高不是与行长严格线性关联的公式。

### 12. 混合字号优先基线对齐

- **识别**：大标题旁的小链接、时间或单位像悬在半空。
- **调整**：同一阅读行的不同字号文字优先按文字基线对齐；Web 实现可使用 `align-items: baseline`。
- **检查与边界**：用真实字体确认文字落在同一视觉基准上。图标、头像或按钮容器可以按自身结构居中，不能把整页所有元素都改成基线对齐。

## 色彩与识别（13–15）

### 13. 使用色阶系统，而非孤立的几种颜色

- **识别**：背景、文字、边框和状态都从五个孤立色值里硬选，导致过度鲜艳或缺少层次。
- **调整**：建立中性、品牌、必要语义的色阶，并映射到背景、表面、文字、边界和交互状态等用途。没有现成系统时，中性色可从 8–10 档、品牌及所需语义色可从 5–10 档规划。
- **检查与边界**：同类用途使用一致 token，各档在实际使用中有可辨差异且对比合适。按需取用和补齐，不要求单页出现十种颜色，也不必为未使用的状态创建整套色阶。

### 14. 辅助彩色组件优先考虑浅底深字

- **识别**：普通 Badge 或提示用深饱和背景配白字，视觉强度超过主要内容。
- **调整**：浅色背景配深色语义文字，例如浅黄配深棕、浅红配暗红；主要操作仍可用更强的填充。
- **检查与边界**：普通文本与背景实测至少 4.5:1。浅底深字不自动达到 AA 或 AAA；透明度与叠加背景也会改变结果。深色模式根据实际表面调整明暗关系，不能直接复制浅色模式色值。

### 15. 颜色之外再提供一种状态线索

- **识别**：只靠红绿区分涨跌、失败成功，只靠颜色标记选中或错误字段。
- **调整**：配合明确文字、正负号、方向箭头、勾选或警告符号；图表也可用形状、线型或直接标注。
- **检查与边界**：去掉颜色仍能读懂状态。符号需与含义一致；关键状态不能只有一个含义模糊、缺少文字解释的图标。涨跌配色沿用用户所在领域的惯例。

## 质感与图片（16–18）

### 16. 用小面积强调边框建立焦点

- **识别**：结构清楚但缺少焦点，或为了增添活力而给整块背景涂上强色。
- **调整**：在当前导航、关键卡片顶部或提示侧边添加少量品牌或语义强调条。
- **检查与边界**：强调位置有明确意义，未给所有卡片同样加条。强调边框是可选手段；界面已有清晰焦点时无需为装饰增加它。

### 17. 修正图片背景的反差，再调整文字

- **识别**：图片上的文字在部分区域清楚、部分区域消失，换成黑字或白字都无效。
- **调整**：在文字与图片之间加深色蒙版、降低图片反差，或用品牌单色处理；必要时辅以无偏移、较大模糊半径的柔和文字阴影。蒙版不透明度 0.4–0.6 可作为试验起点。
- **检查与边界**：检查文字覆盖区域、不同裁切和响应式尺寸，尤其是最亮或最暗的局部。固定蒙版值或文字阴影不能保证可读；动态图片不稳定时，可给文字独立的稳定底色。

### 18. 素材有适用尺寸

- **识别**：小 SVG 放大后笔画笨重，完整产品截图缩成小卡片后文字像噪点。
- **调整**：小图标保持适合其笔画的尺寸，外加浅底容器撑起布局，或改用为大尺寸设计的图形。截图裁切核心交互，必要时绘制简化示意；位图使用足够分辨率。
- **检查与边界**：按最终展示尺寸看比例与可读性。矢量不模糊不代表任意尺寸都好看；24px 是例子，不是所有图标的强制尺寸。

## 细节与首次使用（19–20）

### 19. 克制分隔线与边框

- **识别**：每层容器、每个列表项都画线，页面像被密集网格切碎。
- **调整**：先尝试背景微差、组间留白或轻微阴影；已有充分分组线索时移除冗余边框。
- **检查与边界**：减少线条后结构仍清楚。输入框、键盘焦点、选中态、复杂表格或难以辨认的边界可能需要保留线条；避免把“克制”变成绝对禁用。

### 20. 优先设计空状态

- **识别**：新用户只看到空白卡片、无用表头或一句“No data”，不知道如何开始。
- **调整**：说明这里将承载什么，提供一个明确且可执行的下一步，如“创建第一个项目”；可选用友好图标或插画，只隐藏在首次无数据时确实无用的筛选、排序等控件。
- **图形语义**：按空状态的原因和下一步选图形。创建场景可用加号；筛选无结果应表达未匹配或查找，不能仅因页面还能创建就沿用加号；错误图形应提示失败或重试。图形不贴切时可以省略，以文案与操作承担说明，不要求每种状态都有插画。
- **检查与边界**：首次无数据、筛选无结果、加载中、错误分别表达。筛选无结果保留清除筛选入口；没有创建权限时提供适合角色的下一步。插画不能代替行动指引，CTA 必须对应可用功能。

## 可选的学习与校准

仅在用户希望提升设计能力或建立素材库时应用：保存优秀界面的局部参考，分析其字重、组内外间距、文字对比和操作层级；复刻一个卡片或表单，通过实际渲染比对微调。练习可先不看源码，生产任务则继续复用已有实现与设计系统。

规则帮助提出调整方向，最终以真实内容、用户任务和实际观感判断；不要把公式准确当作视觉质量的证明。
