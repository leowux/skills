# 可视化展示

将当前主题转化为聚焦的视觉解释。标签和辅助文字使用用户的语言。

默认只选择一种主要格式。仅当用户要求多种格式，或单一格式无法承载必要信息时，
才组合使用多种格式。如果用户明确指定了格式，并且该格式能够忠实表达结果，
则遵循其要求；否则简要说明限制，并使用最接近的合适格式。

## 选择格式

| 格式 | 适用场景 | 交付方式 |
| --- | --- | --- |
| Markdown 表格 | 精确比较、字段映射、矩阵、选项网格和紧凑的结构化事实 | 在回复中提供 GitHub 风格的 Markdown 表格 |
| Mermaid | 流程、时序、状态、实体关系、依赖、架构，以及其他可由带标签的节点和边完整说明的结构 | 在回复中提供带围栏的 `mermaid` 代码块 |
| SVG | 需要 Mermaid 无法提供的几何布局或样式的精确静态布局、自定义图、信息图和简单图表 | 完整且独立的 `.svg` 文件 |
| HTML | 可调输入、模拟、分步演示、动画、复杂 UI 状态，以及需要浏览器行为的交互 | 完整且自包含的 `.html` 文件 |

使用仍能清晰表达内容的最轻量格式。对于精确且重复的字段，优先使用表格而非图；
对于语义关系，优先使用 Mermaid 而非自定义绘图；对于静态视觉，优先使用 SVG
而非 HTML；仅当交互或浏览器布局能显著改善解释时才使用 HTML。如果任何视觉
形式都无法改善简短回答，应简要说明，而不是强行生成装饰性产物。

## Markdown 表格

- 保持列名简短，并使各行可以直接比较。
- 保留精确值、单位和限定条件。若有助于快速浏览，则对齐数值列。
- 普通表格不创建文件，也不将其重复制作成另一种视觉形式。

## Mermaid 图

- 使用与关系匹配的图类型，例如 `flowchart`、`sequenceDiagram`、
  `stateDiagram-v2` 或 `erDiagram`。
- 保持标签简洁，保留有意义的顺序和方向，并且只包含回答问题所需的节点和边。
- 在一个带围栏的代码块中返回有效的 Mermaid 语法。除非自定义样式承载了标签
  无法表达的信息，否则不要使用自定义样式。

## SVG 文件

- 保存包含 SVG 命名空间和响应式 `viewBox` 的完整 SVG 文档，不使用外部资源。
- 包含 `<title>`、`<desc>` 元素和易读的文字标签。将颜色与文字、形状或线型
  结合使用，避免仅依靠颜色传达含义。
- 使用可缩放的几何图形和系统字体。将标签保持在视图框内，并验证文件打开后
  没有裁切或重叠。

## HTML 文件

- 编写包含 `<!doctype html>` 和语义化 HTML 的完整文档。内联所有 CSS、
  JavaScript、数据和自定义资源。使用系统字体，或嵌入所有自定义字体和图标。
  不使用 CDN、网络请求或本地服务器。
- 首次渲染应在交互前就有用。只添加有助于探索所请求概念的控件。
- 同时支持窄屏和桌面宽度，不产生页面级横向滚动。使用原生且可通过键盘操作的
  控件、可见标签、有用的无障碍名称，并为有意义的动态结果使用 `aria-live`。
- 遵循 `prefers-reduced-motion`；不使用循环动画或装饰性动画。

## 交付 SVG 和 HTML 产物

1. 使用用户提供的路径。否则优先使用宿主提供且归当前任务所有的产物目录或
   暂存目录；如果不存在，则在源代码树之外新建一个操作系统临时目录。
2. 选择以 `show-me-` 开头、带有相应扩展名的 ASCII 小写 kebab-case 文件名。
   如果路径已存在，则添加唯一后缀，不要覆盖原文件。
3. 回复前读取或渲染完成的文件。检查主要内容和交互是否正常，并确认没有资源
   缺失、标签裁切或明显的布局问题。
4. 使用可用的宿主预览或文件打开能力打开文件。如果没有，则在安全的情况下使用
   已安装的平台打开程序。不要仅为打开文件而安装软件。如果没有可用的打开程序，
   则跳过打开步骤并继续。
5. 返回绝对路径；如果宿主支持本地文件链接，则将其设为链接。如果打开失败，
   应简要说明并仍然返回路径；绝不能在预览未打开时声称已打开。

## 内容与边界

- 让视觉内容聚焦于用户的问题。内部只放置必要的标题、标签、数值、图例和控件；
  周围的说明文字保持简短。
- 使用用户提供的事实和数据，或从可用来源验证的信息。明确将虚构的示例值标记为
  示例数据。
- 保留用户的术语、单位、顺序和指定的视觉风格。
- 生成的 SVG 和 HTML 文件属于解释性产物。不要修改现有应用，不要用模型稿替代
  用户要求的生产实现，也不要将 HTML 预览描述为可部署的网站。
