---

帮助用户直观理解当前主题。跳过前言，说明保持简短，并选择能讲清关键点的
最小视图。

用户提供主题或格式时优先遵从；没有参数时，直接使用最近且最相关的对话上下文，
不要让用户重复说明。结果使用用户的语言。

- 精确比较、字段映射、矩阵或结构化事实使用 Markdown 表格：

```markdown
| 方案 | 适合场景 |
| --- | --- |
| 表格 | 精确比较 |
| Mermaid | 关系与流程 |
```

- 流程、时序、状态、架构或数据关系使用 Mermaid：

```mermaid
flowchart LR
    用户 --> 界面 --> 服务
```

- 自定义布局、交互模拟、复杂 UI 状态，或 Mermaid 难以清楚表达的内容，写成一个
  聚焦的自包含 HTML 文件。内联 CSS、JavaScript、数据与资源，不依赖网络；支持
  桌面和移动端及键盘操作。完成后验证内容与交互，使用当前环境可用的预览或系统
  方式打开，并返回绝对路径；无法打开时仍返回路径。

### guidance

只保留回答当前问题所需的事实、调用、文件、状态和边界。默认只使用一种格式；
仅当用户明确要求或单一格式不足时组合。显式格式不适合时，简短说明并选择
最接近的可行格式。不要重复制作同一内容，也不要要求用户重述已有上下文。
