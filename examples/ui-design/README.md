# UI Design 示例：项目工作台

使用 `ui-design` 优化的中文项目管理页面，保留桌面表格，并在手机上提供完整字段的紧凑列表与可横向滚动的表格。

直接打开 `index.html` 即可体验搜索、状态筛选、新建项目、CSV 导出、选择与删除。数据为虚构演示数据，仅保存在当前页面内存中，刷新后重置。

状态入口：`index.html?state=empty` 展示首次空状态，`index.html?state=error` 展示加载失败。

优化后进行了实际浏览器验证：25 项检查通过，涵盖原有功能、空状态、键盘焦点、移动端视图切换与选择状态保留；375px 视口无页面横向溢出。桌面文字对比度采样最低为 5.81:1；这些检查不代表完整无障碍认证。
